# Third-party data

This project downloads only small, filtered extracts and records the exact query, access time and SHA-256 hash.

## Eurostat

- Monthly electricity statistics: `nrg_cb_em`.
- Monthly HICP: `prc_hicp_minr`.
- Provider: Eurostat, European Commission.
- Access: Eurostat public dissemination APIs.
- Reuse information: verify the current Eurostat copyright and reuse notice before publishing stored snapshots.

## Open-Meteo

- Historical Weather API, daily temperature variables.
- Paris and Berlin are used as urban proxies and are not national aggregates.
- Open-Meteo historical data may combine observations and reanalysis products.
- Attribution and current licence requirements must be rechecked before publication.

No third-party data or code has been pushed or published by this local run.
